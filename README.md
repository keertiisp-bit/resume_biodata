# 🌸 Keerti - Personal Portfolio Website

Welcome to my personal portfolio website! ✨

This project is a beautiful and responsive multi-page website created using
HTML, CSS, and JavaScript. It presents my personal information, skills,
education, projects, resume, and bio-data in a clean and attractive design.

---

## 🌷 About The Project

This website is designed as a personal portfolio that contains:

- 🏠 Home Page
- 📄 Resume Page
- 👩‍🎓 Bio-data Page
- 💻 Skills Section
- 🚀 Projects Section
- 🎓 Education Details
- 🏆 Achievements
- ❤️ Hobbies
- 📞 Contact Information
- 🌙 Dark Mode
- ✨ Interactive JavaScript Features
- 📱 Responsive Design

The website uses a soft pink, cream, brown, and gold color theme to
create a modern and elegant appearance.

---

## 🛠️ Technologies Used

### HTML5
Used to create the structure and content of all web pages.

### CSS3
Used for:

- Page layout
- Colors
- Animations
- Cards
- Buttons
- Responsive design
- Hover effects
- Dark mode styling

### JavaScript
Used to add interactive features such as:

- 🌙 Dark/Light mode
- ✨ Animations
- 📊 Skill bar animation
- 🔘 Interactive buttons
- 🖱️ User interactions
- 📱 Responsive menu interactions
